# Content Sourcing Guide

이 사이트는 광고수익형 자격증 블로그다. 남의 블로그 글이나 뉴스 기사를 복사하지 않는다. 공식/공개 자료에서 사실, 소재, 질문을 모은 뒤 자체 문장으로 재구성한다.

## 우선 출처

1. Q-Net
   - 자격증 종목, 응시자격, 시험일정, 원서접수, 합격자 발표, 공개문제, 출제기준 확인
   - https://www.q-net.or.kr/

2. Q-Net 국가기술자격 통계연보
   - 접수 상위 종목, 취득자 현황, 연령별 취득자, 검정형/과정평가형 현황 등 글 소재 확인
   - https://www.q-net.or.kr/crf012.do?gId=&gSite=Q&id=crf01209

3. HRD-Net / 고용24
   - 직업훈련 과정, 국민내일배움카드, 직업훈련 키워드 확인
   - https://www.work24.go.kr/

4. NCS 국가직무능력표준
   - 직무 분류, 분야별 능력 단위, 직무 설명 확인
   - https://www.ncs.go.kr/index.do

5. 워크넷 직업정보
   - 직업 설명, 직무 분류, 취업 관련 소재 확인
   - https://www.work.go.kr/consltJobCarpa/srch/jobInfoSrch/srchJobInfo.do

6. 커리어넷 직업백과
   - 청소년/대학생 대상 직업 설명, 관련 학과, 직업 흐름 확인
   - https://www.career.go.kr/cloud/m/job/list

7. KOSIS 국가통계포털
   - 국가기술자격 취득자 현황, 종목별 시험현황 등 통계 기반 글 소재 확인
   - https://kosis.kr/

## 글감 뽑는 방식

- 자격증명 + 대상 독자 조합: "비전공자 정보처리기사", "직장인 전기기사", "대학생 산업안전기사"
- 자격증명 + 고민 조합: "준비 전 체크", "공부 계획", "비용 줄이기", "채용공고 읽기"
- 공식 자료 + 해석 조합: "통계연보에서 많이 접수한 종목", "NCS 기준 직무와 자격증 연결"
- 변동 정보는 고정값으로 쓰지 않고 공식 사이트 확인 안내로 처리

## 글 작성 규칙

- 사실 정보는 공식 출처를 기준으로 확인한다.
- 시험일정, 응시료, 합격률, 접수 기간은 임의로 쓰지 않는다.
- 다른 사이트 문장을 복사하지 않는다.
- 기사 구조는 제목, 요약, 대상 독자, 판단 기준, 실행 순서, 주의점, 공식 링크 순서로 작성한다.
- 각 글은 최소 1,000자 이상, 8문단 이상을 유지한다.
